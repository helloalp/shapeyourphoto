# 弹窗与框体大小规范

- 主要二级窗口标题统一为 `ShapeYourPhoto v.x.x.x - 功能名`，版本号从统一版本入口读取。
- 弹窗底部关键按钮必须固定可见；窗口缩小时内容区滚动，按钮区不被文本挤走。
- 进度窗口只保留一个明确取消入口，关闭叉号与取消按钮走同一路径。
- 修复完成、扫描摘要、相似图、cleanup 等列表型窗口优先给列表和详情区域高度，摘要只能使用紧凑信息条、chip 或短行。
- 最小尺寸附近必须给出统一提示“已达到最小可用窗口大小”，不得让控件互相遮挡。

## 设置页与小弹窗

- 设置页底部保存、取消和状态区必须固定可见；每个具体页签使用自己的滚动容器，不能让底部按钮随内容一起滚走。
- 页签文字在中英日下可能明显变长，设置窗口需要允许横向空间不足时仍可操作，内容靠页内滚动解决。
- 小弹窗默认尺寸必须优先保证主要内容和底部按钮完整显示；内容过高时只滚动说明区，按钮区固定。
- “选择文件夹扫描范围”等决策弹窗的默认最小尺寸不得低于 `680x460`，普通 1080p 屏幕上不得超出屏幕可用高度。
- 右侧信息区的内层滚动条应贴近右边缘；Notebook 页签内不应再额外叠加会造成滚动条之间空隙的大内边距。
