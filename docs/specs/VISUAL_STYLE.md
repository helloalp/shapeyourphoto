# 图形设计与视觉风格规范

- ShapeYourPhoto 是桌面工具，不做营销式 hero。第一屏应直接呈现可操作的导入、列表、HUD、EXIF 和 Console。
- 默认主题为“经典清绿”，升级后不应让用户感觉应用变成另一个产品。
- 新 UI 使用系统字体，优先 Microsoft YaHei UI / Segoe UI，等宽日志优先 Consolas / Cascadia Mono；不得提交字体文件。
- 主题必须使用 token：主色、强调色、背景色、面板色、按钮色、文本色、表格选中色至少要定义清楚。
- 禁止一味堆叠同色系卡片。分析、修复、清理、相似图等工作型界面应安静、可扫描、可重复使用。
