# ShapeYourPhoto 1.2.5

日期：2026-05-12

本轮清理应用身份、统一 Windows 源码包启动入口，并整理根目录结构；不改变分析算法、修复策略、用户数据格式或云端更新协议。

## 应用身份

- `APP_ID` 改为 `helloalp.shapeyourphoto.desktop`，用于 Windows 任务栏 AppUserModelID。
- macOS bundle id 保持 `com.helloalp.shapeyourphoto`，Windows Inno Setup AppId GUID 保持不变，避免影响安装包升级关系。
- 用户数据目录继续使用 `Helloalp/ShapeYourPhoto`；当前代码没有把旧 `APP_ID` 用作设置、统计、缓存或更新数据目录。

## 文档清理

- 清理正式代码、CHANGELOG 和 1.1.7 历史记录中残留的开发工具或上游 AI 名称。
- 历史记录中需要保留语义的位置改为“平台检测修复”或“维护修复”，避免后续维护者沿用旧身份表述。

## Windows 启动入口

- 普通用户只需要双击根目录 `start.bat`。
- `start.bat` 负责查找 Python，随后交给 `tools/launcher/start_helper.py` 显示中英文阶段提示、检查运行依赖并启动应用。
- 依赖齐全时直接启动；缺少 Pillow、numpy、platformdirs、cryptography 等运行依赖时，才执行 `python -m pip install -r requirements.txt`。
- 依赖安装失败时保留控制台窗口和下一步说明，不让双击流程直接闪退。
- 旧 `setup_deps.bat`、`start_app.bat` 和 `start_app.vbs` 移到 `tools/legacy/`，仅作为兼容入口；普通用户文档不再要求使用它们。
- 启动流程不运行 benchmark、目录扫描或更新包下载。

## 无 Python 设备

- 源码包在未安装 Python 的设备上不能直接运行。
- `start.bat` 会显示 Python 缺失说明并保留窗口。
- 推荐普通用户使用正式打包发布物；源码包继续面向开发者和高级用户。

## 根目录布局

- 应用代码移入 `src/`；根目录保留 `app.py` / `app.pyw` 作为薄启动器。
- benchmark 工具移入 `tools/benchmark/`。
- 启动 helper 移入 `tools/launcher/`。
- 旧启动脚本移入 `tools/legacy/`。
- `assets/`、`build/`、`docs/`、`test/` 和被忽略的 `private_docs/` 保持独立目录。
- 本轮确认旧内层代码目录已不存在；`app.py`、`app.pyw`、`start.bat`、`tools/launcher/start_helper.py`、`tools/benchmark/benchmark_test_images.py`、`build/`、updater/cloud 相关入口均已按当前 `src/` 布局解析路径。

## 用户可见文案

- 设置 schema 增加 `language` 字段，默认 `zh_CN`，并通过 `src/ui/language.py` 维护当前语言状态。
- `src/ui/display_names.py` 改为按当前语言返回内部 code/enum 的显示名，补齐 `en_US` 显示映射；业务存储仍保留英文内部值。
- 设置页语言选项保存后会更新当前语言状态；部分已创建窗口文案仍需重启应用后完全生效。
- 设置页更新区域只展示 `Shape Your Photo vX.Y.Z` 和“版本 ID N”，不再展示构建 ID、更新 URL 或公告 URL。
- 设置页移除开发者模式入口，继续保留底层开发者能力边界，不在普通设置流程暴露实现入口。
- 不适合保留复核、EXIF 保存确认、文件列表、扫描范围/进度、统计、修复完成摘要和更新/公告错误提示进一步改成面向普通用户的中文文案。
- 新增 `docs/specs/USER_FACING_LANGUAGE.md`，并同步 Console 可读性和 display mapping 规范。
- 本轮只收口已开始的语言基础设施和已触碰窗口文案，不做全局硬编码文案替换。

## 更新历史与窗口体验

- 应用内更新历史改为按版本分组的编号列表，不再直接显示 Markdown 列表符号或反引号。
- 不适合保留图片复核窗口改为“列表 + 选中详情区”：列表支持横向滚动，选中后可完整查看主要原因、状态、严重程度和置信度。
- 主窗口右上角新增“置顶”按钮，按钮使用图标在上、文字在下的布局；再次点击可取消置顶。

## Updater 鲁棒性

- Manifest、公告和更新包请求统一使用 ShapeYourPhoto User-Agent，不再使用 Python 默认请求标识。
- 手动检查更新遇到握手超时或网络超时时，显示简短中文提示，设置窗口和主界面仍可继续操作，具体异常写入 Console。
- 独立 updater 的取消按钮和关闭叉号改为立即关闭 updater，不再显示“下一个安全点退出”之类的等待提示；下载阶段增加更长读取超时和多次重试。
- updater 回滚增加超时出口，失败时显示中文提示，不再无限等待。
- updater 在更新包大小或 sha256 校验失败时输出 expected/actual/url 细节，并先切换为可关闭状态再显示失败提示；如果 `package_size` 与 manifest 不一致但 sha256 正确，会记录警告并继续更新。
- `managed_files` 包含 updater 本身时，更新包会生成临时 stager，在当前 updater 退出后完成最后替换并重启主程序。
- 新增 `src/updater_bootstrap.py` 和 `src/updater_v2.py`。主程序优先启动 bootstrap，后续正常 OTA 由新版 updater 负责。
- 新版客户端支持 `external_download_only` / `disable_in_app_update` 类型 manifest：只显示更新说明，不显示内置“更新”按钮，用于必须手动下载完整包的特殊发布。
- 更新 manifest 预留目标版本范围筛选：服务端可用 `target_min_version_id` / `target_max_version_id` 或未来的 `updates` 多候选列表，让不同客户端接收不同更新提示。
- 新增 `tools/update_smoke/update_resilience_smoke.py`，覆盖版本比较、UA、超时、取消、sha256/size 错误、zip-slip、updater 自更新、删除不存在路径、替换失败与回滚场景。
