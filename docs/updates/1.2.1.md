# ShapeYourPhoto 1.2.1

1.2.1 是一个很小的界面文案更新版本。本轮不改图像分析算法、修复算法、cleanup 删除逻辑、相似图逻辑或 updater 协议。

## 主要变化

- 关闭流程不再显示 `Closing ShapeYourPhoto` 文案。
- 主界面“作者官网”按钮改名为“官网”。

## 涉及文件

- `app_metadata.py`
- `ui_app.py`
- `README.md`
- `docs/CHANGELOG.md`
- `docs/updates/README.md`
- `docs/updates/1.2.1.md`
