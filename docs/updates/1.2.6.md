# ShapeYourPhoto 1.2.6

日期：2026-05-16

本轮重点处理批量任务响应、启动与旧文件整理、主界面右侧信息架构、多语言、扫描规则、性能摘要和 GPU 状态识别。分析与修复质量策略不降低，修复完成详情继续使用专用窗口。

## 启动与旧文件整理

- `start.bat` 在缺少 Python 时会调用 PowerShell 辅助脚本，识别 Windows 版本、系统架构和 `winget` 可用性。
- 检测到 `winget` 时，用户可以选择启动 Python 官方安装流程；安装失败或未选择自动安装时，窗口会保留并显示官网安装路径。
- 正常启动前会扫描旧布局残留的根目录旧模块、旧启动入口和旧运行缓存；命中项移入 `data/update_quarantine/legacy_cleanup/<timestamp>/`，并写出 `legacy_cleanup_report.json`。
- 整理流程不会处理 `.git`、`.github`、`private_docs`、`test`、`data`、`tmp`、`_repair`、`_cleanup_candidates` 等受保护位置，不永久删除用户图片或仓库文件。

## 任务响应

- 主界面任务进度区现在承载扫描、分析和修复状态，耗时任务进行时仍能看到当前阶段、数量和耗时。
- UI 回调队列增加单次处理预算，避免大量进度和 Console 刷新一次性占满主线程。
- 进度窗口更新不再每次强制同步布局，降低批量任务中点击主窗口、切换选中项时的卡顿风险。
- 扫描、分析和修复继续使用 run_id / cancel_event 防护，迟到回调不会写回新任务。

## 导入与列表

- 文件夹扫描改为主界面内进度，不再额外弹出扫描进度窗口；取消扫描会保留已发现并已导入的图片。
- 拖入单张、多张图片会直接加入列表；拖入文件夹会按当前扫描规则处理；不可读取文件会被简短提示并写入 Console 摘要。
- 文件列表支持 Ctrl+A 全选、反选、清除选择、Delete/右键批量移出。移出只影响列表，不删除原图。
- 批量修复目标语义保持不变：真正多选优先，其次使用勾选集合，单个焦点行只服务“修复当前”。
- 设置页的扫描规则扩展为前缀、后缀、包含三类文件夹名称规则，列表显示序号并支持多选删除；`_repair` 前缀始终保留。

## 主界面与窗口

- 右侧栏改为同级标签页：诊断、预览图、属性 / EXIF、Console。诊断页承载指标图、风险、摘要和建议；预览图页显示更大的当前图片。
- 主窗口默认尺寸按屏幕可用空间调整，1080p 下避免超出屏幕，2K / 4K 下提高默认占比。
- 修复完成详情、相似图窗口和不适合保留图片窗口提高默认尺寸，列表区域获得更多可见高度。
- “查看”菜单新增“最近修复摘要”，可重新打开最近一次修复完成详情；没有记录时显示自然空状态。
- 顶部菜单在“查看、设置”右侧新增“帮助”，其中“帮助与官网”会展示简短说明并可打开官网。

## 多语言与显示

- 语言偏好扩展为简体中文、English、日本語，设置会持久化到 `app_settings.json`。
- `ui/language.py` 增加面向菜单、帮助入口和右侧标签的翻译表；`ui/display_names.py` 补充日语语言分支。
- 语言保存后会立即刷新主窗口菜单、顶栏按钮、筛选下拉、列表/清理表头、右侧标签页、预览空状态和设置窗口框架；筛选判断继续使用内部 issue code，不依赖当前显示语言。
- `app_metadata.CHANGELOG_I18N` 支持 v1.2.6 起按当前语言显示更新历史；旧版本继续回落到中文事实记录。
- 新增界面清晰度 / 密度选项，高清细节模式会提高字体、行高和按钮留白，适合高缩放或高分辨率屏幕。

## 性能

- 扫描完成会记录 wall time、访问文件数、导入数量和跳过文件夹数量。
- 导入和扫描后不再整批清空缩略图缓存，减少重复解码和列表刷新压力。
- 主列表缩略图缓存改为带文件时间戳的 LRU，避免超大文件夹长时间浏览时缓存无限增长，也避免原图修改后继续显示旧缩略图。
- 右侧大图预览改为后台解码，快速连续切换图片时只保留最新一次预览请求，过期解码结果会被丢弃。
- 分析和修复保留既有阶段耗时、慢图和慢阶段摘要；Console 刷新继续合并写入。

## GPU 状态

- GPU 状态拆分为硬件、可用运行后端和当前任务使用状态。
- 设置页后台检测 GPU，不阻塞窗口打开。
- 能区分硬件可见、加速组件准备情况和当前任务使用状态；加速组件未准备时安静使用 CPU。
- 当硬件可见但加速组件未准备时，设置页会给出可理解的下一步说明；默认运行依赖仍保持轻量。
- 当前版本仍不声称默认 GPU 参与分析或修复，只有检测和后端状态说明。

## 交互修正

- 设置页点击“保存设置”后不再关闭窗口，保存会立即应用到主界面，用户可以继续调整其他选项。
- 右侧预览图首次显示时会在布局稳定后重新按可用区域生成原图预览，并按显示区域降采样解码与缓存渲染尺寸；解码在后台完成，避免超高清图片选择时阻塞主界面。
- 主列表、不适合保留复核和相似图复核的缩略图会按目标尺寸降采样读取 JPEG，降低大文件夹首次加载和复核窗口打开时的解码开销。
