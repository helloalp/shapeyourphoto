# ShapeYourPhoto 1.2.4

1.2.4 是用于测试云端 updater 链路的小版本。本轮不做其他功能修改，不改图像分析算法、修复算法、cleanup 删除逻辑、相似图逻辑或 updater 替换协议。

## 主要变化

- 版本号更新到 `1.2.4`。
- `version_id` 和 `build_id` 更新到 `8`。
- 用于验证 `1.2.3 -> 1.2.4` 的更新检测、下载、校验和替换流程。

## 涉及文件

- `app_metadata.py`
- `README.md`
- `CHANGELOG.md`
- `docs/updates/README.md`
- `docs/updates/1.2.4.md`

## 验证重点

- `python -m compileall -q .` 应通过。
- 从 1.2.3 测试目录启动后，检查更新应能发现 1.2.4。
- 更新完成并重启后，当前版本应显示为 1.2.4。
