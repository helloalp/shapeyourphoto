# 1.1.7 更新记录

日期：2026-05-09

本轮融合 main 已合入的跨平台打包、拖放、平台检测和 Codex 修复，同时重新叠回本地 v1.1.7 的 UI、设置、数据、HiDPI、Splash、修复取消和文档规范升级；不改变分析算法、修复风格、相似图算法或 cleanup 安全规则。

## main 与本地修改融合

- 保留 main 的跨平台桌面打包：macOS Apple Silicon `.dmg`、Windows Inno Setup 安装包、`build/` 配置、`assets/app_icon.icns` 和 GitHub Actions Release workflow。
- 保留 main 的跨平台拖放：Windows 使用原生 `drag_drop.py`，macOS / Linux 使用 `tkinterdnd2`，根窗口由 `dnd_support.create_root()` 创建。
- 保留 main 的平台检测修复：`paths.IS_WIN` / `IS_MAC` / `IS_LINUX` 集中管理平台判断，避免非 Windows import-time 崩溃。
- 保留 main 的用户数据目录迁移和 PyInstaller 资源加载：设置、统计和资源路径继续走 `paths.py`。
- 保留本地 v1.1.7 的 repair cancellation、Console 设置、主题、HiDPI、Splash、`ui/` 包结构、安全 EXIF 编辑和统计扩展。
- `app.py` 使用 `create_root()` 保住跨平台拖放，同时在根窗口创建后配置 Tk scaling、字体、Splash 和窗口显示流程。
- `app_settings.py` 使用用户数据目录迁移路径，同时保留 schema 2、Console 时间模式和主题字段。
- `stats_store.py` 在 Windows 写入用户数据目录下 `usage_stats.dpapi` 并使用 DPAPI；非 Windows 不伪装加密，回落到用户数据目录内 JSON。
- `drag_drop.py` 修复融合后的缩进错误，避免 `WindowsFileDropTarget` 在 import 阶段触发 `NameError` 导致 `start_app.bat` 无窗口。
- 本文件、根 `CHANGELOG.md`、`README.md` 和 `app_metadata.CHANGELOG` 都统一归入 1.1.7，不新增额外版本线。

## 计时、进度与取消

- 修复批次面向用户的“本轮修复总耗时”使用 `total_wall_time`，即真实等待时间。
- `worker_cumulative_time` 继续作为并发 worker 累计耗时诊断字段，明确标注不是用户等待时间。
- 分析/修复进度窗口底部按钮区固定，关闭叉号与取消按钮走同一路径。
- 修复取消会恢复修复前分析状态快照，清理已写出的非覆盖输出；覆盖原文件修复会先创建 `_repair_cancel_backups` 并在取消时恢复。

## 主界面

- 移除主界面顶部长期占位的“任务进度”栏；分析、修复、扫描进度使用独立进度弹窗和底部状态。
- 顶部路径栏改为横向长栏，长路径更容易理解。
- “读取目录”和“导出清理清单”主入口移除。目录读取由“选择目录”、拖入目录和分析前补扫描触发；清理仍通过 cleanup candidate 安全复核。
- 缩略图列表标题右侧展示总数、已分析、问题图、失败、清理候选和相似组统计。
- 右侧重新强调 HUD 与问题强度条图；文件名、尺寸、识别结果、推荐修复和风险值压缩为摘要，EXIF/属性与 Console 保留在下方标签页。

## Console 与设置

- `app_settings.py` schema 升级到 2。
- 设置窗口新增 Console 页，时间戳支持：
  - 24 小时制：`[20:28:14]`
  - 12 小时制：`[08:28:14 PM]`
  - 启动后经过时间：`[T+00:20:28]`
- 设置变化只影响新 Console 日志，不重写旧日志。
- 设置窗口新增外观 / 风格页，包含经典清绿、石墨灰、影像蓝、暖白纸和高对比五套主题 token。

## HiDPI 与 Splash

- Windows GUI 启动前启用 DPI awareness。
- Tk scaling、默认字体和 ttk 样式按 DPI 与系统字体配置；优先 Microsoft YaHei UI / Segoe UI，等宽日志优先 Consolas / Cascadia Mono。
- Python GUI 启动阶段新增居中 Splash，主窗口准备好后自动关闭，异常时不阻塞主窗口。

## 扫描与加载

- 目录扫描阶段显示进度弹窗：正在扫描目录、已处理/已发现数量、当前路径和 elapsed time。
- 扫描完成后进入“正在加载图片”阶段，避免用户看到静默空窗期。
- Console 只输出扫描摘要；完整跳过目录明细进入“最近扫描摘要”窗口。

## 二级窗口与显示名

- 主要二级窗口标题统一为 `ShapeYourPhoto v.x.x.x - 功能名`。
- 修复完成详情窗口摘要区改为紧凑 chip 信息条，优先给筛选、列表和详情滚动区域空间，底部关闭按钮固定可见。
- 新增 UI display mapping 层，内部英文 code/enum/storage 保持不变；UI 对 issue、scene/portrait/exposure/color、repair method/policy、outcome、worker/GPU/scan/Console 时间模式和 perf stage 做中文化显示。
- 未知值以 `未知类型（raw_value）` 一类形式回退。

## 统计与用户数据

- UI 文案从“累计统计”改为“统计”。
- 统计新增修复尝试、跳过/no-op、回退、cleanup candidate、相似组、平均分析 wall time、平均修复 wall time、最近运行时间、按天和按版本聚合计数。
- 持久化从明文 `usage_stats.json` 迁移到被忽略的 `data/usage_stats.dpapi`。
- Windows 使用用户级 DPAPI 加密。DPAPI 不可用时不得伪装加密。
- 旧 `usage_stats.json` 存在时先读旧数据、写入新 store，成功后复制为 `usage_stats.migrated-*.json` 备份标记，不直接删除。

## EXIF 安全编辑

- 右侧“属性 / EXIF”页新增“编辑”按钮，默认只读。
- 当前只允许 JPEG / TIFF 写入安全文本字段：标题 / 描述、作者、版权、关键词 / 备注。
- 禁止修改相机型号、镜头型号、拍摄时间、EXIF Orientation、ICC Profile、软件内部标记和任何会破坏显示方向或修复链路的字段。
- 保存前创建 `.metadata-bak*` 备份；写入失败会尽量恢复原文件并提示。

## UI 包与文档规范

- 新增 `ui/` 包：`window_titles.py`、`display_names.py`、`themes.py`、`hidpi.py`、`splash.py`、`metadata_editor.py`。
- 根级 `ui_*` mixin 保留为兼容层，避免一次性大搬迁造成循环 import。
- 新增 `docs/specs/`，记录视觉风格、弹窗尺寸、HUD/条图、Console、display mapping、用户数据/加密和设置扩展规范。
- 新增 `docs/technical/UI_SETTINGS_DATA.md`，记录 UI 包、Console 设置、主题 token、DPAPI 统计和 EXIF 编辑边界。

## 验证

- `python -m compileall -q .` 通过。
- `stats_store` 读写迁移验证通过，`data/usage_stats.dpapi` 可生成且不进入 git。
- `start.bat` / `start_app.bat` 保持短启动链路，未加入依赖安装、benchmark、扫描或耗时逻辑。

## 手工验收建议

- 4K 或高缩放屏幕下观察主窗口、设置窗口、进度窗口、修复详情和 Console 字体清晰度。
- 切换三种 Console 时间模式，确认新日志时间戳变化且旧日志不重写。
- 选择包含大量子目录的目录，确认扫描和加载都有进度提示，Console 不刷完整跳过目录。
- 打开设置、扫描范围、扫描摘要、修复准备、修复完成详情、cleanup candidate、相似图、统计等主要弹窗，确认标题格式和底部按钮可达。
