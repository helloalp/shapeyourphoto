# ShapeYourPhoto 1.2.2

1.2.2 是用于测试云端 updater 链路的小版本，重点修复启动后云端弹窗可能导致主界面无法点击的问题。本轮不改图像分析算法、修复算法、cleanup 删除逻辑、相似图逻辑或 updater 替换协议。

## 主要变化

- 修复启动后云端公告和自动更新弹窗可能锁住主界面输入的问题。
- 云端公告已读后不再重复弹出。
- 公告中的更新入口会先关闭公告，再进入检查更新流程，避免叠加两个模态窗口。
