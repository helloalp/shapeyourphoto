# ShapeYourPhoto 1.2.3

1.2.3 是用于继续测试云端 updater 链路的小版本，重点修复启动时同时收到更新提示和云端公告造成的弹窗竞争风险。本轮不改图像分析算法、修复算法、cleanup 删除逻辑、相似图逻辑或 updater 替换协议。

## 主要变化

- 自动更新提示和云端公告改为排队显示，避免并行弹窗抢占输入。
- 保留 1.2.2 的云端弹窗修复：窗口显示并置顶后再进入模态输入状态。
- 确认 1.2.1 旧目录卡住的触发条件是：服务器同时返回新版本 manifest 和命中 `notice-1.2.1` 公告，旧版会并行创建两个强制模态弹窗。

## 涉及文件

- `app_metadata.py`
- `ui/cloud_actions.py`
- `README.md`
- `docs/CHANGELOG.md`
- `docs/updates/README.md`
- `docs/updates/1.2.3.md`

## 验证重点

- `python -m compileall -q .` 应通过。
- 临时伪装为 `1.2.1 / version_id=5 / build_id=5` 时，云端 manifest 应能检测到更高版本。
- 从 1.2.2 或后续版本启动时，自动更新提示和云端公告都可以显示，但不应在同一时间叠加弹出。

## 兼容测试提示

如果要从未修复的 1.2.1 目录测试更新，服务器公告建议临时避开 1.2.1，例如关闭公告、移除公告里的更新按钮，或把公告版本范围排除 `version_id=5`。客户端 1.2.3 会在更新后修复并行弹窗问题，但不能反向改变已经运行中的 1.2.1 旧弹窗代码。
