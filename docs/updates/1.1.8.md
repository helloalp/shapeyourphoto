# ShapeYourPhoto 1.1.8

1.1.8 是一次功能、UI、安全更新链路和文档体系升级。本版本以当前代码为准，旧文档若与 1.1.8 行为冲突，应按本文件和当前源码修订。

## 主要变化

- EXIF 编辑升级为普通安全模式与开发者高级模式两层。普通模式只允许标题、作者、版权、关键词等安全文本字段；开发者模式在会话解锁后显示更多相机、拍摄和 GPS 摘要字段，并在存在 `exiftool` 时解锁 GPS/XMP/IPTC 高级写入。
- 任何字段值包含 `shapeyourphoto` 的 EXIF/XMP/IPTC 信息都视为软件完整性/溯源字段，在 UI 中灰显并禁止保存，高级模式也不能绕过。
- 修复右侧 HUD、指标条、百分比和值重叠问题。条图为百分比和值预留固定右侧列，HUD 文本使用换行和最小宽度约束。
- 设置页新增“更新”“公告”“开发者模式”页面。自动检查更新默认开启且 1.1.8 暂不允许关闭；开发者模式使用本机密码哈希或环境变量解锁，仅本次运行有效。
- 启动流程调整为先显示居中 Logo/Splash，再显示主窗口；关闭流程统一进入 Closing Splash，窗口关闭按钮、Alt+F4 和更新器关闭路径共用同一关闭入口。
- 主界面新增“作者官网”按钮，打开 `https://helloalp.top/tools/shapeyourphoto`，失败时提示并尝试复制链接。
- 新增云端更新和公告客户端、签名校验、包 sha256 校验、带回滚能力的独立 `updater.py`。
- 新增 `private_docs/for_developer/` 与 `private_docs/for_developai/` 私有文档体系，并将 `private_docs/` 加入 `.gitignore`。
- 暂时移除 GitHub 自动打包 workflow。后续发布以服务器 manifest、签名包和独立 updater 链路重新设计。

## 安全边界

- 云端 manifest/messages 必须带签名；客户端使用 Ed25519 公钥验证。公钥由 `assets/update_public_key.pem` 或环境变量配置，私钥不得进入公开仓库。
- 本地云端状态使用随机本机 secret 做 HMAC 完整性保护，不使用 base64 冒充加密。
- updater 只处理 manifest 管理的应用目录文件，删除项移动到 `data/update_quarantine/`，不会处理用户图片、`data/`、`private_docs/`、`test/`、`benchmark_reports/`、临时目录等本地数据。
- 更新失败不会阻止主程序启动；更新过程中下载、校验、解压、替换任一步失败都会中止并尽量回滚。

## 版本记录语言规范

- `app_metadata.py` 内置 `CHANGELOG`、根 `CHANGELOG.md` 和 `docs/updates/<version>.md` 默认使用中文书写。
- 文件名、函数名、模块名、环境变量、协议字段、第三方库名和内部 code/enum/storage value 保留英文原文。
- 不得把整条英文 release note 直接放入应用内版本历史；面向用户和维护者的解释性文字应写成中文。
