# ShapeYourPhoto 1.1.9

维护说明：1.2.5 已统一源码包启动入口，日常启动现在只需双击根目录 `start.bat`；本文件中的旧启动步骤只保留历史上下文。

1.1.9 是一次设置、更新入口、标题和文档整理版本。本轮不改变图像分析算法、修复策略或清理安全规则。

## 主要变化

- Console 时间戳新增带时区格式，显示为类似 `[20:28:14 UTC+09:00]` 的形式，便于跨地区排查日志。
- 主界面“分析全部”按钮改为普通按钮样式，不再使用加粗强调。
- 客户端更新 manifest URL 固定为 `https://helloalp.top/shapeyourphoto/updates/manifest.json`。
- 客户端云端消息 URL 固定为 `https://helloalp.top/shapeyourphoto/updates/messages.json`。
- 上述两个 URL 不在设置页公开显示，不允许用户修改，也不写入普通 `app_settings.json`。
- 配色方案设置页只显示配色名称，不再公开具体颜色 token。
- 设置页“更新”页面新增当前版本信息和“检查更新”按钮，显示版本名、`version_id` 和 `build_id`。
- 设置页说明文案改为更短、更面向用户，减少开发者实现细节。
- 主窗口标题改为 `Shape Your Photo | v1.1.9 | by Helloalp`。
- README 改为用户入口，Windows 用户按 Release 下载、运行 `setup_deps.bat` 和 `start_app.bat`；macOS 安装说明后续补充。
