# ShapeYourPhoto 1.2.7

## 1.2.7 (2026-05-23)

- 顶部操作区精简为更清晰的图片导入、目录导入、分析、修复与格式转换入口，不同语言下不再挤压按钮文字。
- Windows 拖放改为系统原生接收方式，可将图片、文件夹或混合内容直接拖入主窗口；忙碌时会给出明确提示。
- 同名图片以灰色圆圈信息标记提示，悬停可区分路径，列表选择、右键菜单和键盘操作保持可用。
- 相似图片比较窗口支持点击整张图片卡片切换选择状态，减少只能点击小控件的操作负担。
- 设置页的扫描忽略规则默认显示 `_repair`、`fmt_output` 与 `.metadata-bak`；可删除、补充或恢复默认，实际扫描会严格按当前列表执行。
- 属性与 GPS 窗口读取和保存时保持界面响应；保存失败时提供易懂说明并保护原图片。
- 检查更新、更新窗口与公告操作会跟随当前界面语言显示；语言文件不完整时仍可正常检查与关闭窗口。
- 调整 Console 选择文字和窗口尺寸变化后的刷新方式，在浅色、深色主题及缩放过程中保持内容清晰。
- 核心弹窗统一尺寸与居中行为，关闭与后台任务回调处理更稳定。
