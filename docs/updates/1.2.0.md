# ShapeYourPhoto 1.2.0

维护说明：1.2.5 已统一源码包启动入口，日常启动现在只需双击根目录 `start.bat`；旧文中关于必须先运行 `setup_deps.bat`、`start_app.bat` 不安装依赖的规则仅保留为 1.2.0 历史上下文。

1.2.0 是 updater 正式可用基础版本。本轮不改变图像分析算法、修复算法、cleanup 删除逻辑或相似图逻辑，重点是把云端更新链路从 1.1.8/1.1.9 的试运行状态整理为可发布、可测试、可打包的基础版本。

## 主要变化

- `APP_VERSION` 升级为 `1.2.0`，`APP_VERSION_ID` 和 `APP_BUILD_ID` 升级为 `4`。
- `cryptography>=42.0.0` 纳入 `requirements.txt`，源码包用户通过 `setup_deps.bat` 正式安装。
- `setup_deps.bat` 继续作为唯一批处理依赖安装入口；`start.bat` 和 `start_app.bat` 不安装依赖、不下载更新、不运行 benchmark、不做耗时扫描。
- 新增 `assets/update_public_key.pem`，作为正式包内置更新公钥来源。
- `SHAPEYOURPHOTO_UPDATE_PUBLIC_KEY_FILE` 保留为开发测试覆盖方式，日常使用不需要手动设置。
- 缺少 `cryptography` 时，签名验证错误会明确说明本地 Python 环境缺少依赖，并提示运行 `setup_deps.bat` 或 `python -m pip install cryptography`。
- PyInstaller spec 补齐 `cryptography` Ed25519 验签相关 hidden imports，降低打包漏收动态导入模块的风险。
- 文档补齐 1.2.0 -> 1.2.1 的真实更新链路测试流程，并修正旧的错误启动入口、在设置页填写更新/消息地址等过时步骤。

## 验证重点

- `python -m compileall -q .` 应通过。
- `python -c "from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PublicKey; print('local cryptography Ed25519 ok')"` 应通过。
- `start.bat` / `start_app.bat` 不包含 `pip install` 或耗时检查。
- `assets/update_public_key.pem` 只包含公钥，不包含私钥。
- 设置页不显示 manifest URL 或 messages URL 输入框。
- 1.2.0 发布后，用 1.2.0 的源码包或安装包作为本地基线，检查服务器上的 1.2.1 manifest 并执行 updater 更新。
