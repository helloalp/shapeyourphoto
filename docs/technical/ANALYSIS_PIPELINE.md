# 图像分析流水线

本文简述 ShapeYourPhoto 内部从读取图片到输出诊断结果的通用逻辑流与入口边界。

> [!NOTE]
> 包含具体的 `working image` 解析参数、多维感知维度的运算细则，以及多线程写回同步边界的具体变量名等技术机密，已移至内部加密维护百科 `private_docs/for_developai/` 中。

## 模块入口与承载关系

- `src/analyzer.py`：仅作为面向外部调用暴露的接口层，不包含复杂的业务逻辑。
- `src/analysis/core.py`：负责编排单张图片的特征分析流水线。
- `src/analysis/portrait.py`：专注人像增强与保护策略的前置检测。
- `src/analysis/discard.py`：识别极低质量图片，生成“不适合保留”的建议。

## 流水线数据流向

单次分析的过程严格按序执行以下抽象阶段：
1. **统一读取与归一化**：自动读取文件，完成 EXIF 色彩/方向的归一化，生成一套专供高密度分析的小规格图片结构。
2. **多维特征计算**：针对场景、清晰度、噪点、色偏、人物等元素并行执行探测。
3. **输出构建**：汇总全部维度的得分，将其整合成面向前端渲染的标签 (Issues) 与图表指标，并独立生成诊断清理建议。

## 批次与调度

为保障界面响应速度，系统允许执行大批量图片的并发分析：
- 分析任务被分配至后台 Worker。
- 系统保证每一轮批次分析都持有独立的令牌；针对“随时取消”操作，任何延迟回调的非当前轮次结果会被丢弃拦截，绝不会发生旧任务数据污染当前 UI 的情况。
